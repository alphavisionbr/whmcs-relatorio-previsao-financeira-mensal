# Segurança

Não publique vulnerabilidades ou dados sensíveis em Issues públicas.

Envie relatos responsáveis para **contato@alphavision.com.br**.

Ao relatar um problema, remova ou anonimize nomes, e-mails, domínios, valores, IDs, faturas, credenciais, tokens e demais dados reais do ambiente WHMCS.
