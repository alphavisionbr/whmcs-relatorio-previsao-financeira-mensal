# Suporte

Antes de abrir uma Issue, consulte o `README.md` e o `CHANGELOG.md`.

Ao relatar um problema com **Previsão Financeira Mensal**, informe:

- versão do relatório;
- versão do WHMCS;
- versão do PHP;
- filtro ou período utilizado;
- comportamento esperado;
- comportamento observado;
- passos para reprodução.

Anonimize todos os dados reais do ambiente.
