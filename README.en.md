# Alphavision® WHMCS Relatório Previsão Financeira Mensal

Custom WHMCS report.

**Current public version:** 1.0.0

[Versão em Português](README.md)

## About

Valores previstos e já faturados a receber no mês selecionado, sem duplicidade.

This report is distributed as an independent project so it can be installed, updated and versioned without requiring the other reports in the Alphavision® collection.

## Installation

Extract the installable Release ZIP at the root of a self-hosted WHMCS installation.

The report will be installed at:

```text
modules/reports/previsao_financeira_mensal.php
```

## Public version lineage

Public version **1.0.0** starts an independent versioning cycle for this report.

Derivado do relatório `previsao_mensal.php` do pacote interno Alphavision WHMCS Reports 1.0.5.
